## About the course

Learners develop a user-centered design from a brief through flows, wireframes, components, visual layouts, testing and export. The current v12 courseware uses Claude Design; the provider's registration page may still describe the older UXPin version.

## Learning outcomes

1. Identify user needs and information flows.
2. Develop user-interface prototype components.
3. Design and validate a user interface.
4. Document and export a design for handoff.

## Topics covered

- Design workflow, research evidence, personas, journeys and information architecture.
- Claude Design briefs, wireframes, components, tokens and interaction states.
- Responsive layouts, accessibility, print hierarchy and collateral design.
- Design-system setup, usability metrics, iteration and handoff documentation.

## Labs

1. [Clinic Booking Mobile](labs/lab-01-clinic-booking-mobile/README.md) — patient booking and rescheduling flow.
2. [Responsive Retail Web](labs/lab-02-responsive-retail-web/README.md) — product discovery and cart states.
3. [Festival Flyer and Landing Page](labs/lab-03-festival-flyer-and-landing-page/README.md) — A5 flyer and campaign page.
4. [Programme Brochure](labs/lab-04-programme-brochure/README.md) — six-panel tri-fold proof.
5. [Claude Design System](labs/lab-05-claude-design-system/README.md) — tokens, components and variants.
6. [Validation and Handoff](labs/lab-06-validation-and-handoff/README.md) — task tests, iteration and export.

Each lab has its own brief, approved content, visual assets, local HTML specimen, review form and printable PDF guides. The [Learner Guide](courseware/LG-Mastering%20UI%20Design%20Techniques%20for%20Web%20and%20Mobile-v12.pdf) contains the detailed procedures. The slide deck presents mechanisms and evidence without click-by-click instructions.
