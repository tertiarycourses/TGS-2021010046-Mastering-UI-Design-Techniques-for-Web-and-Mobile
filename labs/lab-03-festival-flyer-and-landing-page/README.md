# Lab 03: Festival Flyer and Landing Page

## Client brief

A community arts festival needs an A5 print flyer and matching mobile landing page for free workshops.

## Outcome and acceptance

A5 flyer, QR destination landing page and print proof. 3 mm bleed; 5 mm safe zone; matching event details.

## Materials

- `brief.md` — client constraints
- `assets/content.csv` — approved facts and copy
- `assets/brand.svg` — editable visual asset
- `specimen.html` — local browser preview and fallback
- `review.md` — evidence form

## Detailed procedure

1. Open Claude Design at https://claude.ai/design and start a new project. Confirm that your account and plan provide access; if unavailable, use the included HTML specimen to complete the design reasoning and evidence tasks.
2. Read brief.md and assets/content.csv. Write a design brief naming the audience, primary task, required content, device or print size, constraints and acceptance criteria: 3 mm bleed; 5 mm safe zone; matching event details.
3. Prompt Claude Design: “Create a festival flyer and landing page for Neighbourhood Arts Week. Use the attached brief and content. Show task flow, hierarchy, components, states, responsive or print constraints, and a design rationale. Do not invent fees, dates, medical claims or contact details.”
4. Inspect the first draft. Mark each unsupported assumption in review.md. Compare every headline, price, date, action and contact with assets/content.csv.
5. Ask for one focused revision at a time: correct hierarchy, missing error state, contrast, focus order, small-screen layout or print safety. Save before and after evidence.
6. If using a design system, upload the included brand reference, review the extracted palette/type/components, correct mismatches, then test on a sample page before publishing it.
7. Export the current work as PDF or HTML where supported. For print work, inspect panel order, safe margins, image resolution and a PDF proof; for web/mobile, test at the specified viewports.
8. Complete review.md with an evidence table: criterion, observed result, screenshot/file, defect, revision and retest result. Submit the export plus review.md.

## Verify and submit

Confirm the deliverable, 3 mm bleed; 5 mm safe zone; matching event details. Keep the final export, source project link if available, and review evidence in this lab folder.
